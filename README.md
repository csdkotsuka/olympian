# 🏅 Olympian — 世界大会・アジア大会 日本代表選手名鑑ポータル

> **Olympian (olympian-8f55c)** は、世界大会やアジア競技大会などに出場する日本代表（TEAM JAPAN）トップアスリートの情報を集約・配信する選手名鑑ポータルシステムです。
> バックエンドには **Google Cloud / Firebase Firestore** を採用し、大会や選手データの継続的なアップデートおよび将来の世界大会（オリンピック・世界選手権等）の拡張に対応しています。

現在、第1弾として**「第20回アジア競技大会（愛知・名古屋2026、2026年9月19日〜10月4日）」**の日本代表・注目選手データを配信中。

---

## 🚀 Firebase / クラウドアーキテクチャ

本システムは **Firebase (Firestore)** と連携し、動的にクラウドデータベースからデータを読み込みます。

### 1. データ構造設計（マルチ大会対応）

将来の大会追加をスムーズに行える階層構造になっています：

```
competitions/ (コレクション)
  └── {competitionId}/  (例: 'asian-games-2026', 将来: 'olympics-paris-2024', 'olympics-la-2028')
        ├── (メタ情報: 大会名, 会期, 日程, 会場, 公式URL等)
        ├── athletes/ (サブコレクション)
        │     └── {athleteId}/  (個人注目選手データ: プロフィール, 実績, 批評, メダル速報等)
        └── teams/ (サブコレクション)
              └── {teamId}/     (チームデータ: 全登録選手ロスター配列, 批評, 戦績等)
```

### 2. データ初期化・更新コマンド

```bash
# 依存関係のインストール
npm install

# Firestoreへの初期データシード（個人25名 + チーム6競技109名）
npm run seed

# Firestoreセキュリティルールのデプロイ
npm run deploy:rules
```

### 3. 今後の世界大会追加フロー
1. `seed_firestore.js` または管理画面/スクリプトで新たな `competitionId`（例: `olympics-la-2028`）を作成。
2. 同一スキーマで `athletes` と `teams` を登録。
3. フロントエンドの `js/firebase-data.js` の `CURRENT_COMPETITION_ID` を切り替えるだけで、新大会の名鑑として即座に機能します。

## 🌟 主な特徴とレイアウトの工夫

### 1. 競技別・種目別に迷わずアクセスできるナビゲーション
- **競技大カテゴリタブ**: 陸上、競泳・飛込、体操、格闘技（柔道・レスリング・フェンシング）、ラケット（卓球・バドミントン）、アーバンスポーツ（スケートボード・ブレイキン）、eスポーツ、球技（サッカー・バスケ）をワンタップで切り替え可能。
- **種目連動ドロップダウン**: 選択されたカテゴリに応じて該当種目のみを絞り込み。
- **リアルタイム複合検索**: 選手名（漢字・ひらがな・英字）、種目、所属、出身地、実績キーワードでインクリメンタル検索。
- **ソート機能**: おすすめ・注目度順、50音順、競技別順での並び替え。
- **お気に入り（ピン留め）機能**: 気になる選手を「★」で保存し、いつでも一覧可能（ブラウザローカルストレージ連携）。

### 2. 今大会結果（メダル・順位）の完全整理 ＆ メダル色絞り込み・最後のシーン動画リンク
- **メダルの色（金・銀・銅）による瞬時フィルタリング**:
  - ページ上部の「🏅 今大会メダル獲得結果で絞り込み」バーから、金メダル 🥇、銀メダル 🥈、銅メダル 🥉 をワンタップで絞り込み可能。
  - 各メダルごとの獲得数バッジ（金: 17名 / 銀: 5名 / 銅: 3名）をリアルタイム表示。
- **「最後のシーン（決定的瞬間）」ハイライト動画リンク（YouTube等）**:
  - 全選手および全チームに、金メダル獲得・激闘の勝敗を決めた「最後のシーン（劇的ビックスロー、豪快な一本、最終トリック着地、サービスエース、歓喜のノーサイド等）」を収録。
  - 各カード、クイック表示モーダル、詳細ページのすべてに**「▶️ 最後のシーンを見る」**直リンクボタンを配置し、YouTube等の公式ハイライト映像へ直接アクセス可能。

### 3. チームスポーツ（球技・団体種目）全登録選手の完全網羅と種目個別表示
- **全登録選手ロスター（109名）を完全収録**:
  - ⚽ サッカー男子（U-23日本代表 22名）
  - 🌸 サッカー女子（なでしこジャパン 22名）
  - 🏀 バスケットボール男子（AKATSUKI JAPAN 12名）
  - 🏐 バレーボール男子（龍神NIPPON 14名）
  - ⚾ 野球男子（侍ジャパン・社会人日本代表 24名）
  - 🥎 ソフトボール女子（日本代表 15名）
- **種目個別切り替え機能**:
  - サブナビゲーションのピルボタンにより、各チームを個別に切り替えて単独表示可能。
  - 各チームの**監督・主将・大会目標・スローガン・日程・会場**をヘッダーバナーで整理。
  - **ポジション別クイック絞り込み**（サッカー: GK/DF/MF/FW、野球: 投手/捕手/内野手/外野手 等）に対応。
- **全登録選手の詳細カード**:
  - 特大背番号バッジ、ポジションバッジ、所属チーム、生年月日・年齢・身長体重、プレイスタイル解説。
  - **事実に基づいた客観的批評**（強み・課題・引用元メディア/関係者ソースを明記）。
  - 各選手の**公式SNS（Instagram, X, YouTube等）**リンク。
  - クイック詳細モーダルで即座に深掘り情報を閲覧可能。

### 3. 充実した1ページ分の選手詳細ページ（個人注目選手）
- 選手カードの「詳細プロフィール」または個別URLから、約A4 1ページ／Web 1画面分のリッチなドキュメントを表示。
- **掲載項目**:
  - 公式ポートレート＆大会バッジ
  - 基本プロフィール（年齢、生年月日、出身地、身長体重、所属）
  - 経歴・これまでの歩み（Bio）
  - 主要大会ハイライト戦績（タイムライン）
  - プレイスタイル＆世界を制する武器（技術的解説）
  - **専門家・メディアによる客観的分析・批評**（世界トップの強み・事実に基づいた課題／懸念点・引用元ソースを明記）
  - **公式SNSアカウント**（Instagram, X, YouTube等の公式ハンドル・直リンク）
  - 愛知・名古屋2026への決意とメッセージ
  - 大会スケジュール＆観戦のツボ
  - 「印刷 / PDF保存」対応（Print CSS最適化済み）
  - 前後の選手へのスライド移動ナビゲーション

### 4. 愛知・名古屋2026を象徴するモダンデザイン
- 愛知・名古屋の気品と伝統を表現するロイヤルパープルとゴールドを基調とした洗練されたスポーツUI。
- モバイル・タブレット・デスクトップ完全対応のレスポンシブデザイン（CSS Grid、Flexbox）。
- 外部APIやCDN画像に依存せず、完全自立で即座に高速表示。

## 🚀 ローカルでの閲覧方法

外部サーバーやビルド不要で、ブラウザで直接 `index.html` を開くだけで閲覧可能です。

ローカルWebサーバーを起動して確認する場合：
```bash
# Pythonの簡易サーバーを起動
python3 -m http.server 8000

# ブラウザで以下にアクセス
# http://localhost:8000/
```
